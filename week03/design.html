WDD Design Principles

This page demonstrates basic web design principles.

Key Principles

  • Usability
  • Accessibility
  • Visual Hierarchy
  • Consistency

Example of Visual Hierarchy

Headings are larger and bolder than paragraphs to guide the reader's eye.

Accessibility Considerations

Using semantic HTML elements like <h1>, <p>, and <ul> helps screen readers understand the content structure.
